## Code is open. The name is not.

The Strata compiler is free software under **GPL-3.0** (see [`LICENSE`](LICENSE)). You are
free to use, study, modify, and redistribute the *code* under those terms.

The **name and branding are separate from the code license.** The GPL gives you rights to
the software; it does **not** give you rights to the "Strata" name. This is the same split
the Linux kernel, Firefox, and Rust use to keep a single, trustworthy identity while the
code stays open.

## What this means

**You may:**
- Use the name to refer to *this* project ("built with Strata", "a Strata library",
  "compatible with Strata") — ordinary, truthful, nominative use.
- Fork and redistribute the code under the GPL.

**You may not, without permission:**
- Name your fork or a derived product "Strata", or a confusingly similar name, or use the
  Strata logo/branding. **A distributed fork must use a different name.**
- Imply your product is official, endorsed by, or affiliated with the Strata project.

If you distribute a modified version, give it your own name and make clear it is not the
official Strata.
